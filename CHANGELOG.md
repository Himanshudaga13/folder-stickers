# What's new

## 1.1.1 (29 September 2026)

- Mac: fixed notes not showing after a folder window goes from full screen back to normal size
- Updated contact details in the licence shown during installation

## 1.1.0 (28 September 2026)

First public release.

- Sticky notes that stay inside a folder, in the same place, with the same text
- Bold, italic, underline, strikethrough and tick-box checklists
- Six colours and a transparency slider
- Notes follow the folder window, and hide within a fraction of a second when it closes
- Change every shortcut and the right-click menu text in **Shortcuts & settings**
- Mac: Finder toolbar button and ⌘⇧S shortcut
- Windows: right-click "Add sticker here" and Ctrl+Shift+S shortcut
